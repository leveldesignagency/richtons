# About page — sectors typography (reference)

| Element | CSS class (`about/page.module.css`) | Font size | Line height |
|---------|-------------------------------------|-----------|-------------|
| “Sectors we support” heading | `.sectorsTitle` | `clamp(2rem, 3.85vw, 2.95rem)` | heading default (~1.15 via layout) |
| Intro paragraph under heading | `.sectorsIntro` | `clamp(1.08rem, 1.42vw, 1.22rem)` | **1.42** |
| Active sector description (panel body) | `.sectorPanelBody` | `clamp(1.06rem, 1.25vw, 1.15rem)` | **1.48** |

Hero stat labels use `.heroStatItem` (no boxed containers — flex row/wrap).
